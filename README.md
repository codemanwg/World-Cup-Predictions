# World Cup Predictions

2026 世界杯淘汰赛多模型比分预测记录。基于小组赛与淘汰赛数据，对每场比赛给出 90 分钟常规时间比分预测、简要分析与信心指数，赛后同步实际比分与命中状态。

## 模型说明

| 模型 | 说明 |
|------|------|
| **DS** | DeepSeek v4 Flash 预测 |
| **Opus** | Claude Opus 4.8 预测（07/06 及之前） |
| **GPT** | GPT 5.5 预测（07/07 起接续 Opus） |
| **Gemini** | Google Gemini 3.1 Pro 预测 |

命中规则：实际 90 分钟比分命中任一列出的预测比分即 ✅。

## 文件结构

| 文件 | 说明 |
|------|------|
| `比分预测.md` | 主文件，每场独立表格，含 DS / Opus 或 GPT / Gemini 三行 |
| `小组赛.xlsx` / `小组赛.md` | 小组赛赛程与战绩 |
| `淘汰赛.xlsx` / `淘汰赛.md` | 淘汰赛赛程与结果 |

## 预测格式

- **比分预测**：主预测（蓝色高亮）/ 备选 1 / 备选 2
- **信心**：★ 一至五星
- **状态**：✅ 命中 · ❌ 未中 · ⏳ 待赛

## 分支

- `2026`：2026 世界杯预测主分支
